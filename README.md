# MediaPulse 🚀

MediaPulse is a lightweight and powerful media extraction tool designed to fetch video information, direct streaming links, and formats efficiently.

## Features 🛠️
* Extract video titles, duration, and uploader details.
* Fetch direct streaming URLs for various resolutions.
* Built with Python using the robust `yt-dlp` library.

## Technologies Used 💻
* **Python**
* **yt-dlp**
